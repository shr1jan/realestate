# Kadel Builders design direction

THESIS: Help a person picture everyday life in a home, then keep a shortlist.
OWN-WORLD: A residential architecture practice: considered photographic crops, warm white, deep olive, editorial serif headings, precise sans-serif controls.
STORY: Search immediately, explore actual property cards, inspect one home, then save or enquire.
FIRST VIEWPORT: Plain top navigation, a two-column search and courtyard photo, then the start of the featured homes collection. At 390 px the content becomes heading, image, search, then homes.
FORM: Candidate 4 (residential architecture practice), seed:34f9b100cd691862. Grounded candidates were architecture journal, neighborhood walking guide, open-house brochure, residential architecture practice, independent travel guide, materials library, landscape garden guide. The user's pinned requirement for simple, rounded and well-considered design governs. Graphic catalog challengers do not improve property clarity; their density discipline is retained in the admin table.

The user delegated brand, market and stack choices, and selected an image concept before implementation. The target is `.design/target.png` (1536 × 1024). The target was inspected. It is a directional reference, not a user-approved pixel-exact specification. No separate image-concept approval was requested because the user delegated sensible defaults and the higher-priority implementation instructions require autonomous completion. All UI text and controls are semantic HTML. The separate generated courtyard image is an illustrative image asset; the target is never used as a UI background.

Public pages use the editorial identity. The admin uses the accent-ladder direction (seed 824517262) through pale olive surfaces, ordinary table and form controls, explicit statuses and compact sans-serif headings. No vanity metrics or decorative charts.

Required captures: desktop, tablet and mobile homepage, browsing results, detail, gallery, sign-in, saved, enquiry and success, admin list and editor. Required interactions: browse/filter/sort, anonymous heart to login, pending save completion, persistent saved home, gallery keyboard dismissal, validation/correction, enquiry submission, admin search and editing.
