# Product
<!-- impeccable:product-schema 1 -->
## Platform
web
## Stack
Delegated by the user: React with Vinext, Cloudflare Workers, D1 persistent storage and R2 photo storage. No prior code existed. Sites provides hosted sign-in; local previews simulate sign-in only on loopback.
## Users
House seekers browse properties and save homes. Administrators create and update listings.
## Product Purpose
Make it easy to browse, inspect and shortlist houses.
## Capabilities and Constraints
Browse listings without signing in. Saving requires login. Contact buttons appear only on individual listing detail pages. A protected admin portal creates and updates listings.
## Evidence on Hand
No supplied listings, photos or brand assets. All initial properties must be identified as demonstration content.
## Open Decisions
The user chose sensible defaults for the brand, market and stack, and selected an image concept before implementation. Stillwell and Austin, Texas / USD are demonstration defaults, not claims about a real agency or its inventory. Real business branding and inventory remain to be supplied before public launch.
## Product Principles
Put homes before sales copy. Preserve the home being saved through login. Authorize administrative changes on the server.
